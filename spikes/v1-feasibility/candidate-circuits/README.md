# Candidate V1 circuits

**Unreviewed research code.** This directory is for measuring representative Circom statements, not for defining the V1 ABI. `circomlib`, `snarkjs`, and the experimental `circom2` npm compiler are pinned here for research only. Their GPL-3.0 licensing and compiler provenance require review before any production stack decision. `poseidon-lite` is used for independent witness construction and must match the circuit vectors.

The private-action candidate proves note membership, current origin approval, ownership, distinct nullifiers, same-origin two-input combination, bounded values, fee conservation, and payment/change inheritance. Shield and private actions bind a digest of exact output payload bytes to the proof; the pool checks that digest. The public-exit candidate proves current-holder ownership and membership without an ASP witness while revealing origin. The circuit alone cannot establish that ciphertext decrypts to the committed note; clients must check before submitting and recovery must verify after decryption. These circuits do not establish durable encrypted-output availability, deposit backing, on-chain vault accounting, or legal clearance by themselves.

After `npm ci`, run `npm run compile`, `npm run inputs`, `npm run witness`, and `npm run negative` in that order. Then run `npm run setup -- shield transfer_one transfer_two withdraw_one withdraw_two public_exit`. Setup uses fixed public entropy **only for local research**. Run `node scripts/prove.mjs shield transfer_one transfer_two withdraw_one withdraw_two public_exit` and `node scripts/encode-solana.mjs` with the same names. `CANDIDATE_ASSET=1 npm run inputs` creates token-selector fixtures; `node scripts/prove-asset1.mjs` proves them. Browser measurements use `npm run serve` and the local CDP runner in `scripts/run-browser-suite.mjs`; they require an installed browser and loopback access. See the parent `RESULTS.md` for measured limits.
