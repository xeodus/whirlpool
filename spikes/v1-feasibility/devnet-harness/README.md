# Throwaway Devnet setup preparation

`node prepare.mjs` generates six fresh **test-only** phase-2 Groth16 keys and a separate pool source copy under `/private/tmp/whirlpool-devnet-*`. It reuses the publicly known research phase-1 transcript, so the keys remain unsafe for real funds. The command does not create a signer, deploy, or send a transaction. The original fixed-key pool and browser benchmark artifacts remain untouched.

To check that the new program really accepts its matching proof, set `WHIRLPOOL_RESEARCH_OUTPUT` to that tree's `candidate-circuits/generated` directory and run `node candidate-circuits/scripts/prove-restored-journey.mjs --emit` from the parent spike. Then run `NO_DNA=1 cargo test --offline --test flow phrase_restored_encrypted_journey_reaches_pool_and_exit` in the isolated `pool/` directory after its `cargo build-sbf`. This checks the SOL local journey only; it is not a public-chain recovery test.

`cargo build-sbf` emits a program-ID keypair beside the `.so`. For the approved, isolated Devnet trial it was retained with the disposable admin, ASP, guardian, pool, and upload-buffer signers in an owner-only directory under `/private/tmp/whirlpool-devnet-7YPNlt/keys` (the program-ID file was under the isolated `pool/target/deploy/`). All six signing files were removed after the approved program closure and admin refund. Never add keypairs or proving artifacts to Git.

`admin-session.mjs` is **retired for funded runs**. The first funded in-memory signer was lost when its process crashed, stranding 4.99989 Devnet SOL after the temporary upload buffer had been closed. The script now accepts only `--check-transport`, which uses an unreachable local RPC and sends nothing. Do not fund another in-memory admin. A future trial needs a recoverable, Devnet-only key strategy and a reviewed transaction plan.

The retired script still contains experimental deployment and action-loading code for forensic review; its funded execution path is disabled. Do not treat that code as a ready administration workflow.

Once a test pool has transactions, `node read-live.mjs <program> <pool>` independently replays finalized standard-RPC history and checks it against the current on-chain pool account. It takes no privacy phrase. A missing transaction, unavailable archive, or state mismatch fails closed.

The copied pool still has fixture origin 55, direct ASP authority, a 32-root window, and test-only proof keys made with public phase-1 entropy. It now rejects malformed packed output records and checks their embedded commitments, but does not prove ciphertext decryptability. It is suitable only for bounded Devnet experiments after each concrete transaction is simulated and reviewed. Do not label it a V1 deployment.
